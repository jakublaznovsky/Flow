# Flow v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Redesign Flow with a sidebar + modern light/dark theme and add project focus, notes/decisions, a focus timer, a Progress view, search and shortcuts.

**Architecture:** New pure model modules (focus, stats, review) plus small project-model extensions; Day files gain an optional `focus` list; UI split into focused components under `src/ui/` while `Board.tsx` stays the top-level component.

**Tech Stack:** unchanged (React 19 + TS + Vite, Vitest + RTL, Tauri 2). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-04-flow-v0.2-design.md` (and v1 spec `2026-11-03-flow-design.md`)

## Global Constraints

- All v1 rules hold (see `CLAUDE.md` Rules): never write a file that failed to parse; no warnings/nags/pop-ups/confirm dialogs; unknown fields and bodies preserved; local-time ISO dates; slugs never change.
- Day `focus` list: keys `ref, title, project, minutes`; omitted from the file when empty.
- Decision line format: `- YYYY-MM-DD: <text>` under `## Decisions`.
- Timer presets: 15, 25 (default), 45 minutes. Sessions < 1 minute are not logged. Each session logged once.
- Heatmap: 53 weeks, Monday-first; shade buckets 0 / 1 / 2–3 / 4–5 / 6+.
- Shortcuts (only when no input/textarea/select is focused): `/` search, `n` new task in To do, `b` Board, `p` Progress, `o` Notes, `w` Week, `r` Weekly review.
- Existing exports kept: `Board` default (props `store, settings, now?, onReady?`), `handleDrop`, `usePromotion`, `DropContext`, `BoardApi`. `src/main.tsx` must keep working unchanged.
- Existing tests keep passing (update selectors only where the redesign changes structure; never weaken assertions).

## Review Focus

1. A v1 day file without `focus` round-trips byte-identical in meaning and gains no `focus:` key (Task 1).
2. Adding a decision to a body with no `## Decisions`, with one at the end, and with one followed by another section (Task 1).
3. Timer: pause/resume accounting, stop at < 1 min, finishing exactly once, starting a second session while one runs (Task 5).
4. Streak/week/heatmap across month/year boundaries and DST (use local Date arithmetic, never ms/86400000 rounding without care) (Task 2).
5. Keyboard shortcuts must not fire while typing in any field (Task 3).
